# Workout Guide visual assets

These selected SVG exercise frames are copied from
[Workout Guide by Bryl Lim](https://github.com/bryllim/workout-guide) at commit
`ba0b709cb20430361b2cb33aaadd20998164a916`.

The assets are licensed separately from this app's source code under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The copied
license and attribution notices are in this directory. The original pose
artwork for some frames comes from
[Everkinetic](https://github.com/everkinetic/data), also under CC BY-SA 4.0.

The SVG files are copied unchanged. Syncout changes only how the supplied
frames are displayed locally; it does not install or execute the Workout Guide
package or repository code.

These assets are optional visual demonstrations in the app.
